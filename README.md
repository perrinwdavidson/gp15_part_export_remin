# GP15 Particulate Export and Remineralization

Code for computing ²³⁴Th-derived particulate organic carbon (POC) and particulate nitrogen (PN) export fluxes and remineralization metrics along the GP15 Pacific GEOTRACES transect (Alaska to Tahiti, 2018). The methodology and results are described in:

> **Kenyon, J., Davidson, P., et al. (2026).** Particulate export and remineralization along the GP15 Pacific GEOTRACES transect. *Global Biogeochemical Cycles* (in revision).

---

## Requirements

| Language | Version | Role |
|----------|---------|------|
| MATLAB | R2022b or later | Main pipeline |
| Julia | 1.9 or later | Manuscript and SI figures |
| Python | 3.9 or later | Spatiotemporal kriging via `terraformer` |

**MATLAB toolboxes**: Curve Fitting Toolbox (`csaps`, `fnzeros`), Statistics and Machine Learning Toolbox.

**Julia packages**: pinned in `Manifest.toml` at the repository root. Install with:
```julia
using Pkg; Pkg.instantiate()
```

**Python (`terraformer`)**: install the kriging CLI from `src/toolboxes/terraformer/`. Verify with:
```bash
python -m terraformer._cli.ok --help
```

## Running the Pipeline

**1. Set up data** — download and place `data/` and `plots/` in the repository root (see [Data and Plots](#data-and-plots) above).

**2. Set up Python** — install and verify `terraformer` (see [Requirements](#requirements)).

**3. Run from MATLAB**:

For a full reproducibility run (pipeline + golden-file creation + golden-file validation):
```matlab
% from the repository root
run('runGp15.m')
```

`runGp15.m` runs the full pipeline, then calls `runTests` twice: the first call generates the golden file from the fresh output; the second call validates all four tests against it. Both runs must pass before the output is considered confirmed.

To run the pipeline alone (routine use):
```matlab
run('scripts/gp15Model.m')
```

`setupModel.m` sets all paths automatically via `mfilename('fullpath')` — no manual `addpath` calls are needed. Each stage can also be run standalone in the order below.

### Pipeline stages

| Stage | Script | Output |
|-------|--------|--------|
| 1. Read data | `read_data/readData.m` | `gp15_obs`, `ecco_wo` |
| 2. Particle flux proxy depth | `calculate_ppz/calcPpz.m` | `gp15_ppz` |
| 3. Quality control | `quality_control/doQc.m` | `gp15_obs` (QC'd) |
| 4. Net primary production | `calculate_npp/calcNpp.m` | `gp15_npp` |
| 5. Mixed layer depth | `calculate_mld/calcMld.m` | `gp15_mld` |
| 6. Equilibrium point depth | `calculate_eqp/calcEqp.m` | `gp15_eqp` |
| 7. Upwelling velocity | `calculate_upwell/calcUpwell.m` | `w_<product>.nc` (6 products) |
| 8. Upwelling interpolation | `profile_interpolation/interpData.m` | `gp15_w.*` |
| 9. Vertical Th-234 gradient | `calculate_gradient/calcVertGrad.m` | `gp15_grad` |
| 10. Regional delineation | `regional_delineation/delineateRegions.m` | `regions` |
| 11. POC:Th ratio regression | `regress_ratio/regressRegionalRatio.m` | `ratioPoc*`, `ratioPn*` |
| 12. Data collation | `collate_data/collateData.m` | `gp15_inputs` |
| 13. Flux model | `model/runModel.m` | `gp15_flux*`, `depthData`, `table1`, `table2` |

### Upwelling model products

Six ocean reanalysis products are processed. Five independent products form the flux model ensemble; GREP is retained for diagnostic comparison only.

| Product | Institution | Role |
|---------|-------------|------|
| ECCO v4 | JPL/MIT | Reference + ensemble |
| C-GLORS05 (CGLO) | CMCC | Ensemble |
| GloSea5 (FOAM) | Met Office | Ensemble |
| GLORYS2V4 (GLOR) | Mercator Ocean | Ensemble |
| ORAS5 | ECMWF | Ensemble |
| GREP | CMEMS | Diagnostic only |

The reported 2D flux and its uncertainty are controlled by `fluxProduct` and `uncertProduct` at the top of `scripts/model/subroutines/calcStats.m` (both default to `'meanFull'`, the five-product ensemble mean).

### Generating figures

Manuscript and SI figures are Julia scripts in `scripts/plot_data/`. Run the full pipeline first, then from the repository root:
```bash
julia scripts/plot_data/manuscript/fig1.jl
```

## Tests

A suite of four automated tests verifies the core numerical routines and provides a golden-file regression baseline for the full pipeline output.

```matlab
% from the repository root in MATLAB
run('tests/runTests.m')
```

| Test | What it checks |
|------|---------------|
| `testCalcError` | 1D and 2D flux variance formulae against hand-computed synthetic station |
| `testFitPiecewiseRatio` | Recovery of known α, β, z\* from synthetic piecewise-linear profile |
| `testUncertMetrics` | T₁₀₀ and R₁₀₀ uncertainty formulae; verifies Th-234 variance form and ratio cancellation |
| `testGoldenFlux` | Full pipeline regression against `tests/golden/gp15_flux100_golden.mat` |

All four tests pass on the frozen `v1.0-submission` codebase. To update the golden file after an intentional model change, delete `tests/golden/gp15_flux100_golden.mat` and re-run `testGoldenFlux`.
